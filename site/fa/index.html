تیمی

یک تیم روی یک کلید API

هزینه‌ی یک حساب API اوپن‌ای‌آی را می‌دهید و هر کس ورود و سقف خودش را دارد.

  • نام کاربری، رمز و تاریخ پایان با تمدید یک‌کلیکی
  • پلن با سقف ۵ ساعته، روزانه، هفتگی یا هر بازه‌ی دلخواه
  • کلید و سازمان شما به دست هیچ‌کس نمی‌رسد
  • یک نفر را غیرفعال کنید، Codex او همان لحظه می‌ایستد
شخصی

حساب ChatGPT خودتان، همه‌جا

Codex را با اشتراک ChatGPT خودتان روی سرورتان اجرا کنید و از گوشی یا لپ‌تاپ ادامه‌اش بدهید.

  • یک بار روی سرور وارد شوید؛ همه‌ی جلسه‌ها از همان استفاده می‌کنند
  • دستگاه‌هایی مثل «لپ‌تاپ» و «گوشی»، هر کدام با سقف خودش
  • مصرف هر کار جدا، تا ببینید کدام کار پرهزینه است
  • با بستن مرورگر جلسه‌ها ادامه پیدا می‌کنند
هر لاگین ChatGPT مال یک نفر است. این حالت برای حساب خودتان است، نه برای دست‌به‌دست کردن یک اشتراک.

نصب

چند دقیقه تا راه‌اندازی

نصب‌کننده اگر لازم باشد Docker را نصب می‌کند، CodexGate را می‌سازد و یک لینک خصوصی چاپ می‌کند. بقیه‌ی کار در مرورگر است.

  1. یک دستور با root

    فقط پورت‌های آزاد را برمی‌دارد: پنل روی ۸۴۴۳ می‌رود و ۴۴۳ و ۸۰ پیش هر برنامه‌ای که دارد می‌ماند. اگر اتصالتان قطع شود، نصب ادامه پیدا می‌کند.

  2. باز کردن لینک چاپ‌شده

    صفحه‌ی نصب فقط با توکن یک‌بارمصرفش باز می‌شود. مدیر را بسازید، دامنه را بدهید و روش گرفتن گواهی را انتخاب کنید.

  3. گرفتن گواهی

    از پورت ۸۰ اگر آزاد باشد، یا با DNS کلادفلر و یک توکن API که هیچ پورتی لازم ندارد. خودش تمدید می‌شود.

  4. اضافه کردن آدم‌ها

    یک پلن بسازید، کاربر اضافه کنید، و هر کس از صفحه‌ی خودش با یک دستور Codex را وصل می‌کند.

روی سرور

bash <(curl -fsSL https://raw.githubusercontent.com/sadrazkh/CodexGate/main/install.sh)

گزینه‌ها

# the panel on 443 instead of 8443, if 443 is free
bash install.sh --https-port 443
# a memory cap (default: 60% of the server)
bash install.sh --memory 16g
# run it again later to update; your data is kept

یا با Docker به‌صورت دستی

docker build -t codexgate .
docker run -d --name codexgate --restart unless-stopped \
  -p 127.0.0.1:8080:8080 -v codexgate-data:/data \
  -e Gate__Upstreams__0__BaseUrl=https://api.openai.com/v1 \
  -e Gate__Upstreams__0__ApiKey=sk-... \
  codexgate
با هر تغییر، CI آن را روی سروری تازه که پورت ۴۴۳ش گرفته شده نصب می‌کند، از یک مرجع آزمایشی گواهی می‌گیرد، وارد می‌شود و دوباره به‌روزش می‌کند.
امن از همان اول

ساخته شده تا کلید مشترک پیش شما بماند

کلید شما روی سرور می‌ماند. شناسه‌ی سازمان، پروژه و کلید پیش از نمایش از خطاهای سرویس‌دهنده پاک می‌شود.

درخواست‌ها بررسی و بازنویسی می‌شوند. یک بدنه‌ی یکتا، بدون ذخیره روی سرور اوپن‌ای‌آی، شناسه‌ی ایمنی جدا برای هر کاربر، و هیچ چیز شمردنی‌نشده.

برای هر نفر یک حساب سیستمی. جلسه‌های سرور نه فایل‌های هم را می‌خوانند، نه دیتابیس و نه کلیدهای درگاه را.

کلیدها فقط به‌صورت هش. هر جلسه‌ی سرور کلید خودش را دارد که هیچ‌وقت در خط فرمان دیده نمی‌شود.

ورودهایی که به‌موقع تمام می‌شوند. غیرفعال کردن کاربر یا عوض کردن رمز، ورودهای او را همان لحظه می‌بندد.

سخت‌گیری در مرورگر. سیاست محتوای سخت، هدر CSRF برای هر تغییر، کند کردن حدس رمز برای هر آدرس و هر حساب.

پرسش‌ها

خوب است بدانید

تیمم می‌تواند از راه آن یک اشتراک Plus یا Pro را با هم استفاده کند؟

نه. شریک کردن لاگین ChatGPT یک نفر بین چند نفر خلاف قوانین اوپن‌ای‌آی است و حساب را می‌بندند. برای تیم، CodexGate با کلید API اوپن‌ای‌آی کار می‌کند. حالت «حساب ChatGPT خودتان» برای حساب خود هر نفر است، یا یک نفر روی چند دستگاه.

x-ui یا سرویس دیگری روی سرورم خراب نمی‌شود؟

نصب‌کننده فقط پورت‌های آزاد را برمی‌دارد و CodexGate را در Docker روی شبکه‌ی جدای خودش اجرا می‌کند. اگر برنامه‌ای ۴۴۳ یا ۸۰ را گرفته باشد به آن دست نمی‌زند و پنل روی ۸۴۴۳ می‌رود. جلسه‌ها به loopback سرور دسترسی ندارند.

با کدام Codex کار می‌کند؟

Codex CLI، اپ دسکتاپ و افزونه‌ی VS Code همه همان ~/.codex/config.toml را می‌خوانند که دستور آماده برایتان می‌نویسد (فایل قبلی با پسوند .bak نگه داشته می‌شود).

از گوشی هم می‌شود استفاده کرد؟

بله. پنل روی گوشی راحت است، و با جلسه‌های سرور Codex روی سرور اجرا می‌شود و شما در یک تب مرورگر می‌بینید و تایپ می‌کنید. تب را ببندید و کار ادامه دارد؛ از هر دستگاهی دوباره باز کنید و همان صفحه را می‌بینید.

توکن‌ها چطور از سقف کم می‌شوند؟

ورودی تازه و خروجی کامل حساب می‌شوند؛ ورودی کش‌شده به‌طور پیش‌فرض ۰٫۱ حساب می‌شود، چون API حدود یک‌دهم قیمت می‌گیرد. سقف دلاری از جدول قیمتی که می‌گذارید استفاده می‌کند. درخواست‌های در حال اجرا با میانگین اخیر همان کاربر حساب می‌شوند.

اگر وسط نصب اتصال SSH قطع شود چه؟

نصب روی سرور ادامه پیدا می‌کند. دوباره وصل شوید و /var/log/codexgate-install.log را بخوانید؛ اگر هنوز در حال نصب باشد، اجرای دوباره‌ی دستور فقط پیشرفت آن را نشان می‌دهد.

داده‌ها کجاست و چطور پشتیبان بگیرم؟

همه‌چیز در یک دیتابیس SQLite کنار کلیدهای کوکی و گواهی، داخل یک volume داکر است. مدیر هر وقت بخواهد می‌تواند از پنل یک نسخه‌ی سالم از آن دانلود کند.

Codex برای همه، با صورت‌حسابی جلوی چشم.
